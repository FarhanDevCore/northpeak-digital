# Changelog

All steps taken during the development of the NorthPeak Digital landing page.

## [1.0.0] - 2026-07-25

### Added
- Setup Next.js project with App Router and Tailwind CSS.
- Created a separate `components` folder in the root directory for clean code structure.
- Built a responsive Hero section with a call-to-action button.
- Built a Services section showcasing exactly 6 agency services.
- Added a Results section with project metrics and a client quote.
- Added a 3-tier Pricing grid for different business sizes.
- Created a Contact Form with state management to show a success message upon submission.
- Added the required Footer credit link pointing to Digital Heroes.

### Fixed / Changed
- Fixed component import paths in `app/page.tsx` since the project does not use a `src` folder.
