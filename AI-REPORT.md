# AI Tool Usage Report

I used AI during this task to speed up the process of writing Tailwind CSS utility classes and setting up the basic HTML structure for the components. This saved me a lot of time on styling, allowing me to focus on setting up the project architecture correctly.

**Limitations Faced:**
The AI assumes a standard project setup. Since my project was initialized without a `src` directory, the AI gave incorrect import paths at first. I had to manually debug and update the routing structure in `app/page.tsx` to make sure all components connected properly. 

While AI is great for generating repetitive UI blocks, human intervention was necessary to organize the files cleanly, ensure the design matches the criteria, and guarantee the website functions correctly.
